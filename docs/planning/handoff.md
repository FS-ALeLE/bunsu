# 작업 이어 하기 — 수업 설계 대화 기록 요약

claude.ai에서 수업 설계부터 개발 명세서까지 만든 대화(2026-10-09~10-12)의 내용을 다른 PC나 새 세션에서 이어 갈 수 있게 정리한 문서다. 코드 작업 기록은 `docs/process.md`, 개발 기준은 루트 `CLAUDE.md`, 수업 설계는 `docs/planning/lesson-design.md`에 있다.

## 사용자가 처음에 요청한 내용(요지)

- 충남교육청 온수업 수업사례 공모전 출품. 3학년 '분수', 바이브코딩으로 만든 웹앱 활용.
- 디지털교과서로는 한계가 있는 점이 드러나야 함: 교과서 밖의 다양한 분수를 많이 읽고 표현하기, 상호작용.
- 활용 장면이 다양하게: 교사 설명 보조, 태블릿 개별화 학습, 전자칠판 개인 실습, 전자칠판에 여러 명이 동시에 나오는 게임.
- 확산: 잘 만든 프로그램은 링크로 보급, 간단한 것은 사례를 보는 교사가 프롬프트로 따라 만들 수 있게.
- 심사 기준: 목적 및 주제의 적절성 / 내용의 적절성 및 충실성 / 내용의 참신성 및 체계성 / 현장 적용 및 확산 가능성.
- 3~6차시, 과정안 3세트(묶는 방식 자유). 최종 형태는 '2025 우수보고서(사회과)'와 비슷한 보고서.

## 결정한 것

- **6차시, 80분 블록 3세트**(1~2 / 3~4 / 5~6). 성취기준은 계획서대로 [4수01-09], [4수01-11].
- **See·Touch·Play·Share 모델**과 앱 6종(①~⑥) + GAS 대시보드·문제은행.
- **보급 방식**: ②④⑥은 배포형(링크·QR), ①③⑤는 따라하기형(프롬프트 카드).
- **개발 도구**: 배포형은 클로드 코드(이 저장소), 따라하기형은 채팅 한 번으로 만든 결과를 그대로 쓴다.
- **개인정보**: 학생은 학급 코드 + 번호만. 이름·얼굴 저장 안 함.

## 확인이 필요한 것(대화에서 열려 있던 질문)

- **단원 시기**: 설계는 계획서대로 1학기 「분수와 소수」 내용(등분할, 크기 비교)이다. 실제 수업이 2학기라면 2학기 「분수」 단원(묶음 분수, 진분수·가분수·대분수)과 어떻게 연결할지 정해야 한다.
- **원차시 표**: 사용 교과서의 차시명·쪽수로 바꿔야 한다.
- **성취기준 문구**: 학교 교육과정 편제표와 대조.
- **프롬프트 카드 검증**: 따라하기형 3종은 테스트하며 버그를 고친 버전이다. 새 채팅에 카드만 붙여 넣어 결과가 비슷한지 확인하고, 그 화면을 보고서 캡처로 쓴다. 결과가 많이 다르면 카드 문구를 다듬는다.

## 남은 일

1. 수업 실시와 기록 수집(`lesson-design.md` 맨 끝 체크리스트).
2. 보고서 작성: 형식은 '2025 우수보고서(사회과)'와 '2026년도 온수업 사례 공모전 보고서(참고, 우수)'를 비교해서 정한다. 2025 형식의 목차는 1 수업 의도 → 2 관련 교육과정 → 3 차시 지도 계획 → 4 주사용 수업 도구의 이해 → 5 차시별 교수·학습 과정안(+수업 운영 꿀팁) → 6 활동 내용 및 결과·참고자료 → 7 과정 중심 평가 → 8 결론 및 제언 → 부록(활동지).
3. ~~활동지 1~3 만들기~~ → 완료(`docs/report/worksheets/`). 머리 그림은 image-prompts.md로 생성해 넣기.
4. **수업 동영상 준비**: 심사기준(안)에 동영상이 20점이다(`references/README.md`). 전자칠판 배틀, 태블릿 개별 학습, 교사 설명 장면을 촬영 계획에 넣는다.
5. 보고서 형식 결정: `references/README.md` 끝의 '이 수업 보고서에 가져올 것(제안)' 참고.

## 참고 자료(계획서·우수 보고서)

파일은 PC마다 `references/` 폴더에 직접 옮겨 넣는다(공개 저장소라 `.gitignore`로 올라가지 않게 막아 둠). 파일 목록, 2025·2026 우수 보고서의 짜임, 심사기준(안) 배점은 `references/README.md`에 정리했다. 파일이 없는 PC에서도 그 요약으로 참고할 수 있다.

## 다른 PC에서 이어 하기

1. `git clone https://github.com/FS-ALeLE/bunsu` 후 그 폴더에서 클로드 코드를 연다.
2. 미리보기: 저장소 루트에서 `python -m http.server 8125` → http://localhost:8125 (클로드 코드에서는 `.claude/launch.json`의 `static` 설정).
3. 새 세션에 "docs/planning/handoff.md 읽고 이어서 하자"라고 하면 이 문서부터 읽는다.
