# 따라하기 프롬프트 카드 — ①③⑤

생성형 AI(Claude, ChatGPT, Gemini 등)에 카드 하나를 통째로 붙여 넣으면 비슷한 웹앱이 만들어집니다.
- 만들어진 코드를 `.html` 파일로 저장해 브라우저로 열면 됩니다.
- claude.ai처럼 화면 미리보기가 되는 곳에서는 바로 확인할 수 있습니다.
- 결과가 마음에 들지 않으면 아래 '한 문장으로 고치기'처럼 짧게 요청해 고칩니다.

예시 완성본: https://fs-alele.github.io/bunsu/ (모음 페이지의 ①③⑤)

---

## ① 똑같이 나누었을까?

```text
초등학교 3학년 수학 수업에서 쓸 '똑같이 나누었을까?' 웹앱을 HTML 파일 하나로 만들어 줘.

[목적] 도형을 똑같이 나눈 것과 똑같이 나누지 않은 것을 구별하는 연습. 전자칠판에서 교사가 시연하고, 태블릿에서 학생이 혼자도 쓴다.

[화면] 위에 질문("이 원은 똑같이 나누었을까요?"), 가운데에 큰 도형 하나, 아래에 'O 똑같이 나누었어요'와 'X 똑같이 나누지 않았어요' 버튼, 그 아래 '조각 겹쳐 보기'와 '새 문제' 버튼. 맞힌 개수/푼 개수를 위쪽에 표시.

[문제 생성] '새 문제'를 누를 때마다 원, 정사각형, 직사각형, 정삼각형 중 하나를 무작위로 골라 나눈 그림을 만든다. 절반은 똑같이, 절반은 조각 크기가 확실히 다르게 나눈다.
- 원: 2~8조각 부채꼴.
- 정사각형·직사각형: 2~8조각을 세로 띠, 가로 띠, 격자로 나눈다. 정사각형은 대각선으로 2·4조각도 나눈다. 가끔 '모양은 다르지만 크기는 같은 조각'(왼쪽은 작은 네모 2개, 오른쪽은 삼각형 2개)도 섞는다.
- 정삼각형: 2조각(꼭짓점에서 밑변 가운데로), 3조각(무게중심에서 세 꼭짓점으로), 4조각(세 변의 가운데 점을 이어서)으로 똑같이 나눈다. 똑같지 않게 나눌 때는 높이를 같은 간격으로 자른 띠 모양이나, 꼭짓점에서 밑변을 다른 길이로 나눈 조각을 쓴다.
- 똑같지 않은 문제는 가장 큰 조각이 가장 작은 조각보다 1.3배 이상 크게 해서, 눈으로 구별할 수 있게 한다.

[피드백] 정답이면 칭찬 메시지와 짧은 효과음, 오답이면 노란색으로 "다시 생각해 볼까?"를 보여 준다. 답을 고른 뒤 '조각 겹쳐 보기'를 누르면 조각마다 다른 색으로 칠하고, 두 번째 조각부터 하나씩 첫 번째 조각 위로 움직여 겹친다.
- 원래 자리는 점선으로 남긴다.
- 겹칠 때는 조각을 돌리거나 뒤집어 첫 번째 조각과 꼭짓점이 딱 맞게 겹쳐야 한다. 돌리는 방향(시계/반시계)을 틀리면 엇갈리므로, 두 방향 중 더 잘 맞는 쪽으로 돌린다.
- 겹친 뒤에 "조각이 모두 딱 맞게 겹쳐요" 또는 "겹쳐 보니 조각마다 크기가 달라요"를 보여 준다.

[디자인] 전자칠판에서도 잘 보이게 글씨와 버튼을 크게, 밝은 색. 손가락·펜·마우스 모두 잘 눌리게. 인터넷이 막혀도 동작하게 외부 라이브러리·외부 글꼴 없이 만든다.
```

## ③ 분수 비교 돋보기

```text
초등학교 3학년 교사가 전자칠판에서 분수의 크기 비교를 설명할 때 쓸 '분수 비교 돋보기' 웹앱을 HTML 파일 하나로 만들어 줘. 위쪽 탭으로 세 가지 모드를 고른다.

[공통] 분수는 세로로 쓴다(분자 위, 가로선, 분모 아래). '3/4' 같은 빗금 표기는 쓰지 않는다. 읽을 때는 '4분의 3'.

[모드 1 나란히 비교]
- 길이가 같은 띠 두 개를 위아래로 놓고, 각 띠 왼쪽에 그 분수를 크게 쓴다(위 분수는 주황, 아래 분수는 파랑).
- 화면 아래에 위 분수와 아래 분수의 분모(2~12)와 분자를 바꾸는 슬라이더와 −/+ 버튼을 둔다. '두 분모를 같게 묶기' 체크 상자를 켜면 한쪽 분모를 바꿀 때 다른 쪽도 같이 바뀐다.
- 띠의 조각을 손가락으로 누르면 그 조각까지 색칠되어 분자가 바뀐다. 마지막으로 색칠된 조각을 다시 누르면 하나 줄어든다.
- 두 띠 사이에 >, <, = 기호를 크게 보여 주고, 아래에 짧은 설명을 붙인다. 분모가 같으면 "분모가 같으면 분자가 클수록 커요", 둘 다 분자가 1이면 "분자가 1이면 분모가 작을수록 한 조각이 커요".

[모드 2 단위분수 계단]
- 질문: "전체를 똑같이 나누는 수가 많아지면, 한 조각은 어떻게 될까요?"
- '시작'을 누르면 맨 위에 '1'(나누지 않은 전체 띠)부터 2분의 1, 3분의 1 … 8분의 1까지 띠가 한 줄씩 차례로 아래로 쌓인다. 각 줄은 첫 칸만 색칠한다.
- 마지막 줄이 나오면 색칠된 칸의 끝을 잇는 점선 계단을 그리고 "분모가 커질수록 한 조각(단위분수)은 작아져요"를 보여 준다.
- '한 줄씩', '처음부터' 버튼도 둔다.

[모드 3 함정 피자]
- 큰 피자를 3조각으로 나눠 1조각, 작은 피자를 2조각으로 나눠 1조각을 색칠해 보여 준다. 질문: "큰 피자의 3분의 1과 작은 피자의 2분의 1, 어느 조각이 더 클까요?"
- '전체 크기 맞추기'를 누르면 작은 피자가 천천히 커져 큰 피자와 같아진다. 그다음 "전체 크기가 같아지니 2분의 1이 3분의 1보다 커요. 분수를 비교할 때는 전체 크기가 같아야 해요."를 보여 준다.

[디자인] 글씨와 버튼을 크게, 터치하기 쉽게, 밝은 색. 외부 라이브러리·외부 글꼴 없이.
```

## ⑤ 분수 줄 세우기

```text
초등학교 3학년 학생이 전자칠판에서 혼자 연습할 '분수 줄 세우기' 웹앱을 HTML 파일 하나로 만들어 줘.

[공통] 분수는 세로로 쓴다(분자 위, 가로선, 분모 아래). '3/4' 같은 빗금 표기는 쓰지 않는다.

[문제] 위쪽 버튼으로 세트를 고른다.
- '분모가 같은 분수' 세트: 분모가 같고 분자가 모두 다른 분수 카드 4~5장. 예: 7분의 2, 7분의 5, 7분의 1, 7분의 6.
- '단위분수' 세트: 분자가 1이고 분모가 모두 다른 분수 카드 4~5장. 예: 3분의 1, 8분의 1, 5분의 1, 2분의 1.
- 카드는 섞인 순서로 위쪽 카드 칸에 놓인다. '새 문제'를 누르면 바로 전과 다른 문제가 나온다.

[조작]
- 아래에 '작은 수 → 큰 수' 화살표와 카드 수만큼 빈칸(1, 2, 3 …)을 둔다.
- 카드를 손가락으로 끌어 빈칸에 놓는다. 이미 카드가 있는 칸에 놓으면 원래 카드는 위쪽 카드 칸으로 돌아간다.
- 전자칠판·태블릿에서 터치로 끌기가 잘 되어야 한다(포인터 이벤트 사용, 끄는 동안 화면이 스크롤되지 않게).

[확인] 빈칸을 다 채우고 '확인'을 누르면 각 카드 아래에 길이가 같은 띠 모형이 펼쳐져 크기를 눈으로 비교할 수 있게 한다. 맞는 자리는 초록, 틀린 자리는 노란 테두리로 표시하고 "다시 해 볼까?"를 보여 준다. 모두 맞으면 칭찬 메시지와 효과음.

[디자인] 카드와 글씨를 크게, 밝은 색, 외부 라이브러리·외부 글꼴 없이.
```

## 한 문장으로 고치기 (예시)

만든 뒤에 아래처럼 짧게 요청하면 우리 반에 맞게 바뀝니다.

- "분모를 6까지만 나오게 해 줘." (처음 배우는 학급)
- "문제를 소리로 읽어 주는 버튼을 넣어 줘." (한글 해독이 어려운 학생, 다문화 학생)
- "10문제를 풀면 맞힌 개수와 틀린 문제를 보여 주는 결과 화면을 만들어 줘."
- "전자칠판에서 아이들 손이 닿게 버튼을 화면 아래쪽으로 내려 줘."
- "설정 버튼들은 톱니바퀴를 눌러야 나오게 숨겨 줘."
- "틀렸을 때 빨간색 대신 노란색으로 부드럽게 알려 줘."
- (①) "육각형도 넣어 줘. 2, 3, 6조각으로만 나눠 줘."
- (③) "나란히 비교에 두 띠를 겹쳐 보는 버튼을 추가해 줘."
- (⑤) "카드를 6장까지 늘리고, 분모가 다른 분수도 섞는 어려운 세트를 추가해 줘."

## 쓰기 전에 확인할 것

- 똑같이 나눈 그림이 정말 똑같은지, 분수가 세로로 쓰였는지 직접 몇 문제 풀어 봅니다.
- 전자칠판에서 손가락으로 끌기·누르기가 잘 되는지 확인합니다.
- 결과가 예시와 많이 다르면 "예시처럼 ~해 줘"라고 다시 요청하거나, 카드에서 해당 줄을 더 자세히 씁니다.
