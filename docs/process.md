화면은 `docs/screens/`에 있다.

## 0. 전자칠판 동시 터치 확인 (`/tests/multitouch.html`)

- 결과: 손가락마다 색 원·번호·좌표가 따라다니고 '지금 ○점 / 최대 ○점'이 보인다. 1~4칸으로 나눠 칸마다 누른 횟수를 따로 센다.
- 현장 확인: 교실 전자칠판 동시 터치 **4점 이상**(평소 쓰는 다른 프로그램으로 확인) → 배틀 기본 4칸. (처음엔 2×2였다가 수업 확인 후 가로 1×4로 바꿈)
- 화면: `screens/08-multitouch.png`

## 1. 공통 모듈 + 도형 미리보기 (`/common/`, `/tests/shapes.html`)

- 분수 계산·비교·읽기("4분의 3"), 세로 분수 표기, 무작위 생성(직전 문제 반복 없음).
- 도형 6종(원·정사각형·직사각형·띠·정육각형·정삼각형) × 분모 2~12. 모든 모양의 전체 넓이가 같고, 조각 넓이도 모두 같다(미리보기 페이지가 자동 계산: 최대 차이 10⁻¹²% 수준).
- 정육각형은 분모 2·3·6에서만 나온다.
- 화면: `screens/07-shapes-preview.png`

## 2. ② 분수 놀이터 (`/playground/`)

- 자유 탐색: 모양·조각 수 고르기, 끌면서 여러 조각 색칠, [몇 분의 몇일까?]를 눌러야 분수가 보임(수업 확인 후 바꿈, 처음엔 바로 보였음), 읽어 주기.
- 미션: 1단계 보고 쓰기(숫자 패드, 분모부터) → 2단계 읽고 색칠하기 → 3단계 같은 분수 다른 모양(원·띠·사각형) → 도전 모드. 오답이면 조각 번호 힌트, 2번 틀리면 정답 보여 주고 다음 문제.
- 칠판 모드(`?mode=board`): 도형이 화면 높이 70%, 글씨 40px 이상, '분수 카드 뽑기' + 확인.
- 화면: `screens/01-playground-home.png`, `screens/02-playground-board.png`

## 3. ④ 분수 비교 챌린지 (`/challenge/`)

- Lv1 그림 비교 → Lv2 분모가 같은 분수 → Lv3 단위분수 → Lv4 섞기 + 이유 고르기.
- 3연속 정답 레벨 업, 레벨은 내려가지 않음. 같은 유형 2회 오답 → 띠 모형 힌트. Lv4 이유는 정답 판정과 따로 기록(평가 자료).
- 화면: `screens/03-challenge.png`

## 4. 구글 앱스 스크립트 + 교사 대시보드 (`/gas/Code.gs`, `/teacher/`)

- 시트 탭: log, progress, bank, comments, settings. 학생 기기 기록은 대기열에 쌓았다가 한꺼번에 보내고, 같은 기록이 두 번 가도 한 번만 저장.
- 대시보드: 참여 학생·풀이 수·정답률, ② 미션 단계별 / ④ 레벨별 학생 번호, 오답률 TOP5, 문제 승인. 30초마다 새로고침. 학생용 공개 보기는 반 합계만.
- 화면: `screens/06-teacher-login.png`

## 5. ⑥ 분수 스피드 배틀 (`/battle/`)

- 2·3·4칸(기본 4칸), 손가락마다 처음 닿은 칸으로 판정해 칸끼리 간섭하지 않음.
- R1 듣고 고르기 / R2 색칠하기(칸마다 다른 모양) / R3 더 큰 분수 / R4 줄 세우기(끌기). 1·2·3등 표시, 오답은 그 칸만 2초 흔들림, 설명 보너스 +1.
- 화면: `screens/04-battle-setup.png`

## 6~7. ② 출제 모드 + 문제은행 + 사진 문제 (`/playground/?mode=maker`, `/bank/`)

- 모양 → 나누기(경계를 끌어 똑같지 않게도) → 색칠 → 유형(분수 쓰기 / 더 큰 분수 / 똑같이 나누었을까?) → 정답·힌트 → 미리보기 → 제출.
- 학생이 넣은 정답이 그림과 맞는지 앱이 확인한다("그림을 다시 확인해 볼까?").
- 사진 문제: 학생 기기에서 긴 변 1024px로 줄여 보냄. 교사가 승인 화면에서 사진을 보고 승인한다(얼굴·이름 확인).
- 문제은행: 승인된 문제만, 내 문제 제외, 풀고 나면 출제자 힌트·좋아요·한 줄 댓글(금칙어 거름). 칠판 모드는 좋아요 TOP3.
- 화면: `screens/05-maker.png`

## 8. 모음 페이지·QR (`/index.html`)

- 앱 카드(차시별), 학급 코드를 넣으면 학생용 주소·QR에 들어감, QR 크게 보기(전자칠판에 띄우기).
- 선생님 설정: 구글 시트 웹 앱 주소, 분모 상한(예: 8까지), 효과음. 다른 선생님용 시트 연결 3단계 안내.
- QR은 외부 라이브러리 없이 만든다(학교망 차단 대비).
- 화면: `screens/00-index.png`
- 배포 주소: https://fs-alele.github.io/bunsu/ (2026-10-10, GitHub Pages)
- 저장소: https://github.com/FS-ALeLE/bunsu
- QR: 모음 페이지에서 각 앱의 [QR] 버튼으로 크게 띄운다.

## 만들면서 고친 것 (개발 중 확인)

| 발견한 문제 | 고친 내용 |
| --- | --- |
| 도형이 화면에 비해 작게 보임 | 공통 그림판을 250×170으로 줄여 모든 모양이 크게, 크기는 서로 같게 |
| 큰 분모에서 정사각형 세로 띠가 너무 가늘어짐 | 분모 8 이상이면 격자로 나누는 경우를 더 자주 |
| 인터넷이 없다가 다시 연결돼도 기록이 안 감 | 대기열 전송 코드의 멈춤 문제 수정, 끊김 → 재연결 시 전송 확인 |
| 교사 승인 화면에서 사진이 안 보임 | 승인 전에 사진을 볼 수 있게 함(개인정보 확인) |
| 단계 변경 기록이 풀이 수에 더해짐 | 풀이 수·정답률 계산에서 뺌 |
| 휴대폰으로 열면 스크롤이 안 되고, 분수가 칸 밖으로 잘리거나 화면 밖으로 나감 (요청: "QR들어갔더니 화면 스크롤이 안돼. 콘텐츠가 분수가 칸을 벗어나서 짤리는 것이 있고, 화면 범위를 벗어나게 나오는 게 있어.") | 가로 태블릿·칠판에서만 한 화면에 고정하고, 휴대폰·세로 태블릿·낮은 화면은 위아래로 쌓아 스크롤. 분수 글씨를 칸 크기에 맞춰 줄임 |
| 전자칠판에서 위쪽은 아이들 손이 닿지 않음, 배틀 4칸 창문형(2×2) 배치가 불편 (요청: "아이들 키 때문에 높이 배치하면 안돼. 4명이서 하는거 창문형 배치하면 안되고 가로로 배치 해줘.") | 배틀 칸을 가로로 나란히(1×4), 칸 안에서 누르는 그림·카드·버튼은 아래쪽으로. 칠판 놀이터도 도형·버튼을 화면 아래쪽에 |
| 칠판 모드에서 '분수 카드 뽑기'를 하면 분수가 카드 칸을 넘어감 | 카드 칸 높이를 분수에 맞게 고침 |
| 설정하는 부분이 화면에 많이 보여 시선이 분산됨 (요청: "설정은 눌러서 나오거나 드롭다운으로 나오게 하면 되고, 교육적인 부분이 더 크게 노출되게 해줘.") | 효과음·저장 상태·학급 번호·모양 고르기를 ⚙ 메뉴와 '모양 바꾸기' 버튼 안으로. 도형과 분수 칸을 크게 |
| 색칠하는 순간 분수가 보여서 수업 중 "몇 분의 몇일까?" 물어보기 어려움 (요청: "도형에 색칠하고 몇 분의 몇인지 눌러서 확인할 수 있는 기능 추가해줘.") | [몇 분의 몇일까?] 버튼을 눌러야 분수가 보이게(색칠을 바꾸면 다시 가려짐). ⚙ '분수 바로 보이기'로 예전처럼도 쓸 수 있음 |
| ① 똑같이 나누었을까?: 정삼각형 '조각 겹쳐 보기'에서 조각이 별 모양으로 엇갈림 (요청: "정삼각형은 조각 겹치기가 이상해.") | 3등분 조각을 돌리는 방향이 반대였음. 두 방향 중 첫 조각과 딱 맞는 쪽으로 돌리게 고침(모든 모양에서 겹침 오차 0 확인) |
| 출제 모드: 조각 경계를 옮길 때 똑같이 나눈 자리를 알기 어려움 | 똑같이 나눈 자리에 점선 안내선, 가까이 가면 딱 붙고 초록으로 바뀜 |
| 출제 모드: 비교할 분수의 분모·분자 조절 버튼 위치가 분수와 반대 | 분자 버튼은 분자 옆(위), 분모 버튼은 분모 옆(아래)으로 |
| 모음 페이지: 출제 모드가 분수 놀이터 카드에 있음 | 출제 모드(문제 만들기)와 QR을 '우리 반 문제은행' 카드로 옮김 |
| ③ 분수 비교 돋보기: 나란히 비교에서 분자를 버튼으로만 정할 수 있음 | 막대의 조각을 눌러 분자를 정할 수 있게(같은 조각을 다시 누르면 하나 줄어듦) |
| ③ 단위분수 계단: 맨 위 1(전체)이 없고 12분의 1까지 너무 많음 | 맨 위에 1(전체) 줄을 넣고 8분의 1까지만 |
| ④ 비교 챌린지: PC 화면에서 빈 공간이 너무 많음 | 넓은 화면에서 카드·분수·버튼을 화면 크기에 맞춰 키우고 위아래 가운데로 |
| ⑥ 스피드 배틀: 낮은 화면(브라우저 창)에서 시작 화면이 잘림 | 글씨 기준을 화면 높이에도 맞추고, 시작 화면을 줄이고, 그래도 길면 스크롤 |
| 구글 시트를 연결한 뒤 QR로 열면 빈 화면 (요청: "앱스스크립트 연결했어. 그런데 QR찍으면 아무 것도 안나오고 빈 화면이야") | 주소에 붙은 시트 주소(api=)를 읽는 코드가 끝없이 반복되던 문제 수정 → 번호 입력 화면이 바로 나옴 |
