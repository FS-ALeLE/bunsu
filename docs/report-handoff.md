## 3. 앱별 기능 (교육적 의도 중심)

### ② 분수 놀이터
- **자유 탐색:** 원·정사각형·직사각형·띠·정육각형·정삼각형을 2~12조각으로 똑같이 나누고, 손가락으로 끌며 색칠합니다. 색칠한 뒤 **[몇 분의 몇일까?]** 를 눌러야 분수와 "4분의 3"이 나타나고 소리로 읽어 줍니다. 그래서 교사가 "몇 분의 몇일까?" 하고 먼저 물을 수 있습니다. 색칠을 바꾸면 다시 가려집니다.
- **미션 3단계:** 1단계 보고 쓰기(분모부터 숫자 패드로) → 2단계 읽고 색칠하기("7분의 4만큼 색칠하세요" + 읽어 주기) → 3단계 같은 분수를 원·띠·사각형에 모두 색칠 → 도전 모드. 3번 연속 맞히면 다음 단계로 갑니다. 틀리면 조각에 번호(1, 2, 3…)가 붙는 힌트가 나오고, 2번 틀리면 정답을 보여 주고 다음 문제로 넘어갑니다.
- **칠판 모드:** 도형이 화면 높이의 70%, 글씨는 40px 이상입니다. '분수 카드 뽑기'로 문제를 낸 뒤 학생이 나와 색칠하고 확인합니다(릴레이). 누르는 것(도형·버튼)은 아이들 키를 생각해 화면 아래쪽에 있습니다.

### ④ 분수 비교 챌린지 (적응형)
- Lv1 그림 있는 분모가 같은 분수 → Lv2 그림 없이 분모가 같은 분수 → Lv3 단위분수 → Lv4 섞기 + 이유 고르기.
- 두 분수 사이 빈칸에 > < = 를 고릅니다. 3번 연속 정답이면 레벨이 오르고, **레벨은 내려가지 않습니다**(대신 힌트가 나옴).
- 같은 유형을 2번 틀리면 **띠 모형 힌트**가 자동으로 나옵니다(전체 길이가 같은 두 띠로 비교).
- Lv4에서는 "왜 그렇게 생각했나요?"에서 이유를 고릅니다. 이유가 달라도 크기 비교가 맞으면 정답 처리하고, **고른 이유는 따로 기록해 평가 자료로 씁니다.**
- 화면에는 '내 탐험 위치'(Lv)와 푼 문제 수만 나옵니다. 다른 학생과의 순위는 보여 주지 않습니다.

### ⑥ 분수 스피드 배틀 (전자칠판 동시 터치)
- 2·3·4모둠이 칠판 앞에 **가로로 나란히** 서서 각자 칸에서 같은 문제를 동시에 풉니다. 손가락마다 처음 닿은 칸을 기억해, 옆 칸을 건드려도 간섭하지 않습니다.
- R1 듣고 고르기(음성 "5분의 2" → 그림 4개 중 고르기), R2 색칠하기(칸마다 다른 모양), R3 더 큰 분수 고르기, R4 카드 3장 줄 세우기(끌기).
- 1·2·3등 표시, 틀리면 그 칸만 2초 흔들린 뒤 다시 도전합니다. 라운드가 끝나면 교사가 **'설명 보너스 +1'** 을 줍니다(어떻게 풀었는지 말하게 하는 장치).
- 게임이라 기록은 서버로 보내지 않습니다.

### 우리 반 문제은행 (학생 출제)
- **문제 만들기:** 모양 → 나누기 → 색칠 → 문제 유형 → 정답·힌트 → 미리보기 → 제출.
  - 문제 유형: 분수 쓰기 / 더 큰 분수 고르기 / 똑같이 나누었을까?
  - '똑같이 나누었을까?' 문제는 조각 경계를 끌어 일부러 똑같지 않게 나눌 수 있습니다. 똑같이 나눈 자리에는 점선 안내선이 보입니다.
  - 학생이 넣은 정답이 그림과 맞는지 앱이 확인합니다("그림을 다시 확인해 볼까?").
  - 사진 문제: 피자·색종이 등을 찍어 문제로 만들 수 있습니다. 사진은 학생 기기에서 줄여서 보냅니다.
- **교사 승인 후 공개:** 승인된 문제만 나오고, 내가 만든 문제는 나에게 나오지 않습니다.
- **풀고 난 뒤:** 출제자의 힌트, 좋아요, 한 줄 댓글(40자, 금칙어 필터)이 나옵니다.
- **칠판 모드:** 좋아요 TOP3를 크게 보여 줍니다(출제자 번호만 표시).

### 교사 대시보드
- 학급 코드 + 교사 PIN으로 들어갑니다.
- ② 미션 단계별 학생 번호, ④ 레벨별 학생 번호, 오답률 높은 문제 TOP5, 반 전체 풀이 수·정답률을 보여 줍니다. 30초마다 자동으로 새로고침됩니다.
- 문제은행 승인/숨김. 사진 문제는 승인 전에 사진을 보고 얼굴·이름이 없는지 확인합니다.
- **학생용 공개 보기:** 반 전체 합계만 보여 줍니다(개인 번호 없음).

### 확인용 페이지(개발·현장 점검용)
- `tests/multitouch.html`: 전자칠판 동시 터치 수 확인. 교실 칠판에서 4점 이상을 확인했습니다.
- `tests/shapes.html`: 모든 모양 × 분모 2~12의 조각 넓이가 같은지 자동으로 계산합니다.

## 4. 학습 기록과 평가

- 기록되는 것: 문제마다 정답·오답(앱, 단계/레벨, 문제, 학생 답), 미션 단계 변경, Lv4 비교 이유, 문제은행 출제·좋아요·댓글.
- 저장 위치: 교사의 구글 시트(탭: log, progress, bank, comments, settings). 사진은 교사 구글 드라이브 폴더에 저장됩니다.
- 인터넷이 끊겨도 기록은 기기에 쌓였다가, 연결되면 자동으로 보냅니다. 같은 기록이 두 번 가도 한 번만 저장됩니다.
- 평가에 쓸 수 있는 자료: 대시보드의 단계·레벨 분포(누가 어디에 머물러 있는지), 오답률 TOP5(반 전체가 어려워한 문제), Lv4 이유 기록(개념 이해 근거), 학생이 만든 문제(출제 능력).

## 5. 설계 원칙 (학교 현장을 고려한 점)

- **로그인·이름 없음:** 학생은 학급 코드 + 번호로만 들어옵니다. QR에 학급 코드가 들어 있어 번호만 누르면 됩니다.
- **개인정보:** 이름·얼굴을 저장하지 않습니다. 사진 문제는 촬영 화면에서 안내하고, 교사가 승인 전에 확인합니다. 학생 화면 어디에도 다른 학생의 순위·이름이 나오지 않습니다.
- **학교망 대비:** 외부 서버(CDN)·외부 글꼴을 쓰지 않습니다. QR 코드도 프로그램 안에서 직접 만듭니다.
- **설치 없음:** 웹 주소만 열면 됩니다. 태블릿·전자칠판·PC·휴대폰 화면 크기에 맞춰 배치가 바뀝니다.
- **교과서 표기:** 분수는 세로(분자 위, 가로선, 분모 아래)로만 쓰고, "○분의 ○"로 읽어 줍니다.
- **"전체가 같아야 비교할 수 있다":** 모든 모양의 전체 넓이를 같게 맞추었습니다(3~4차시 핵심 개념과 연결).
- **오답을 벌처럼 보이지 않게:** 빨강 대신 노랑 '다시 해 볼까?'를 씁니다. 효과음은 교사가 끌 수 있습니다.
- **전자칠판:** 3m 뒤에서도 읽히게 글씨 40px 이상, 아이들 손이 닿는 아래쪽에 누르는 것을 둡니다.
- **화면 집중:** 설정(효과음·저장 상태·학급 번호·모양 고르기)은 ⚙ 버튼 안에 숨기고, 도형과 분수가 크게 보이게 했습니다.

## 6. 바이브코딩 과정 (보고서 핵심)

### 방법
1. 교사가 먼저 **명세서**를 썼습니다(`CLAUDE.md`): 수업 장면, 만들 앱, 화면 규칙, 개발 순서(0~8단계), 배포 전 확인 목록.
2. Claude Code에 짧은 요청으로 순서대로 만들게 했습니다.
3. 교사가 직접 써 보고 발견한 문제를 **한 문장으로 요청**해 고쳤습니다.

| ① 정삼각형 '조각 겹쳐 보기'가 별 모양으로 엇갈림 | "똑같이 나누었을까? 에서 정삼각형은 조각 겹치기가 이상해." | 조각을 돌리는 방향 오류 수정(모든 모양에서 정확히 겹침 확인) |
| 출제 모드에서 똑같이 나눈 자리를 알기 어려움 | "조각 경계 옮길 때 똑같이 나눈 위치에 그리드 효과" | 점선 안내선, 가까이 가면 딱 붙고 초록으로 바뀜 |
| 비교할 분수의 분자·분모 버튼 위치가 분수와 반대 | "분모와 분자의 설정 위치 반대로(분모가 아래에서 실제 분수의 분모 옆으로)" | 분자 버튼은 분자 옆(위), 분모 버튼은 분모 옆(아래) |
| 출제 모드가 다른 카드에 있음 | "출제모드와 QR은 우리반 문제은행 쪽으로 버튼 옮겨줘." | 모음 페이지 문제은행 카드로 이동 |
| ③ 나란히 비교에서 분자를 버튼으로만 정함 | "분자 설정을 그림 클릭해서도 할 수 있게 해줘." | 막대 조각을 눌러 분자 정하기 |
| ③ 단위분수 계단이 너무 많고 '1'이 없음 | "맨 위에 1을 추가해주고, 아래는 1/8까지만 나오게 해줘." | 1(전체) ~ 8분의 1 |
| ④ PC 화면에 빈 공간이 많음 | "PC로 봤을 때 화면에 빈 공간이 너무 많아." | 넓은 화면에서 크게, 위아래 가운데로 |
| ⑥ 낮은 화면에서 시작 화면이 잘림 | "분수 스피드 배틀 화면 짤려." | 화면 높이에 맞춰 줄이고, 길면 스크롤 |

(개발 중 AI가 스스로 찾아 고친 것: 도형이 작게 보임, 큰 분모에서 띠가 너무 가늘어짐, 인터넷 재연결 시 기록 전송 멈춤, 승인 화면에서 사진 안 보임, 단계 변경 기록이 풀이 수에 섞임. 자세한 내용은 `docs/process.md`)

## 7. 확산 방안 (다른 교사가 쓰는 방법)

- **바로 쓰기:** https://fs-alele.github.io/bunsu/ 에서 학급 코드를 넣으면 학생용 링크와 QR이 만들어집니다. 시트 없이도 모든 앱이 동작합니다.
- **우리 반 기록 모으기 (3단계, 모음 페이지에 안내 있음):**
  1. 구글 시트 → 확장 프로그램 → Apps Script에 `gas/Code.gs`를 붙여 넣고 `setup`을 실행합니다.
  2. 웹 앱으로 배포합니다(실행: 나, 액세스: 모든 사용자). 교사 PIN을 바꿉니다.
  3. 주소를 모음 페이지 '선생님 설정'에 붙여 넣습니다.
- **고쳐 쓰기:** 공개 저장소를 복사해 자기 GitHub Pages에 올리면 됩니다. 빌드나 설치가 필요 없고, 파일 안 설명이 한국어입니다. 분모 범위는 주소에 `?maxd=8`처럼 붙이거나 설정에서 바꿉니다.
- **바이브코딩 따라하기:** 명세서(`CLAUDE.md`)와 요청 문장 표(6장)가 다른 교사의 출발점이 됩니다.

## 8. 아직 확인하지 않은 것 / 교사가 채워야 할 것

보고서에 "확인했다", "효과가 있었다"로 쓰기 전에 교사에게 확인이 필요합니다.

- [ ] 교실 전자칠판에서 배틀 4모둠이 실제로 동시에 눌러 본 결과(개발 PC 모의 터치로만 확인함)
- [ ] 칠판 모드 글씨가 3m 뒤에서 읽히는지
- [ ] 학생 태블릿 기종·브라우저에서의 실제 사용 모습
- [ ] 수업 장면 사진, 학생 반응, 학생이 만든 문제 예시
- [ ] 대시보드 실제 자료(단계·레벨 분포, 오답률 TOP5, Lv4 이유 분포) — 수업 후 숫자
- [ ] 수업 후 고친 것의 전후 화면 캡처(`docs/process.md`의 '수업 후 고친 것' 표가 아직 비어 있음)
- [ ] AI잇다 게시 여부와 주소
