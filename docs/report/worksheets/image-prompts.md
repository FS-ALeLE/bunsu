# 활동지 꾸밈 그림 프롬프트

분수 그림(피자·띠·도형)은 조각 크기가 정확해야 하므로 `make_worksheets.py`가 직접 그린다(`img/`).
이미지 생성 AI는 아래 **꾸밈 그림**에만 쓴다. 활동지 맨 위 왼쪽 칸 [그림 1]~[그림 3] 자리에 넣는다.

세 장이 한 캐릭터로 이어지도록 공통 설정을 먼저 붙이고, 장면만 바꾼다.

## 공통 설정(세 프롬프트 앞에 붙이기)

```text
초등학교 3학년 수학 활동지 머리 그림. '분수 탐험대' 어린이 탐험가 캐릭터(탐험 모자, 작은 배낭, 밝은 표정, 성별이 드러나지 않는 단발머리).
흰 배경, 굵고 깔끔한 검은 선화, 색칠 공부처럼 안이 비어 있는 스타일, 흑백 인쇄에서도 잘 보이게.
정사각형 구도, 글자·숫자·로고 없음, 실존 캐릭터와 닮지 않게.
```

## [그림 1] 활동지 1 — 똑같이 나누어요

```text
탐험가 캐릭터가 둥근 피자 앞에서 피자 칼을 들고, 피자를 똑같이 나누려고 조심스럽게 선을 살펴보는 장면.
```

## [그림 2] 활동지 2 — 어느 분수가 더 클까?

```text
탐험가 캐릭터가 커다란 돋보기로 크기가 다른 피자 조각 두 개를 번갈아 들여다보며 고개를 갸웃하는 장면.
```

## [그림 3] 활동지 3 — 출제자 노트

```text
탐험가 캐릭터가 연필과 노트를 들고 문제를 만들고 있고, 머리 위에 작은 전구가 켜진 장면.
```

## 쓰는 방법

- 생성한 그림은 정사각형으로 저장하고, 한글에서 [그림 ○] 칸을 지운 뒤 '그림 넣기'로 넣는다(너비 약 35mm).
- 다시 만들 때 캐릭터가 달라지면, 첫 그림을 함께 올리고 "이 캐릭터와 같은 모습으로"를 덧붙인다.
- 그림 안에 글자가 생기면 "글자 없음"을 다시 강조해 재생성한다(활동지 글씨와 겹치지 않게).
